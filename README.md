# 🛒 Simple E-Commerce Website

A basic e-commerce web app built using **HTML, CSS, and JavaScript**.  
Products are fetched from a local `products.json` file, and the site includes **Add to Cart** and **Remove from Cart** functionality.

---

## 🚀 Features

- Display products dynamically from `products.json`
- Add items to cart
- Remove items from cart
- Update cart total automatically
- Responsive UI (if applied)

---

## 📂 Project Structure

├── ecom.html # Main HTML file
├── ecom.css # Styles for the app
├── ecom.js # Handles functionality (cart, fetch products, etc.)
├── products.json # Product data (id, name, price, etc.)
└── README.md # Project documentation
